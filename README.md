## Português

Projeto acadêmico desenvolvido durante um período da minha **Iniciação Científica (IC)**, com foco no desenvolvimento de um sistema de edição localizada de imagens guiada por comandos curtos em português brasileiro.

### Sobre o projeto

Durante um período, trabalhei neste projeto com o objetivo de estudar técnicas de **Inteligência Artificial aplicadas à edição de imagens**.

A proposta era receber uma imagem e uma instrução em português, identificar o objeto ou região mencionada e realizar uma edição apenas na área desejada.

Entre as operações estudadas estavam:

- Alteração de brilho
- Alteração de cor
- Remoção simples de objetos
- Identificação e edição de regiões específicas da imagem
- Utilização de modelos de difusão para edição de imagens

### Tecnologias

- Python
- Google Colab
- OpenCV
- PyTorch
- Modelos de difusão

### Estrutura do projeto

- `data/`: imagens e dados
- `docs/`: documentação
- `notebooks/`: notebooks do Google Colab
- `src/`: código-fonte
- `outputs/`: resultados gerados
- `experiments/`: testes e experimentos

### Mudança de projeto

Trabalhei neste projeto durante um período da minha Iniciação Científica. Após esse período, **troquei de projeto**, passando a trabalhar em uma nova pesquisa relacionada à comparação entre **RAG (Retrieval-Augmented Generation) e LLM Wiki**.

Este repositório mantém os estudos, experimentos e materiais desenvolvidos durante o período em que trabalhei com edição de imagens utilizando Inteligência Artificial.

## English

Academic project developed during a period of my **Undergraduate Research Project (IC)**, focused on developing a localized image editing system guided by short commands in Brazilian Portuguese.

### About the Project

During this period, I worked on this project with the goal of studying **Artificial Intelligence techniques applied to image editing**.

The proposed system receives an image and an instruction in Portuguese, identifies the mentioned object or region, and performs an edit only on the desired area.

The studied operations included:

- Brightness adjustment
- Color adjustment
- Simple object removal
- Identification and editing of specific image regions
- Use of diffusion models for image editing

### Technologies

- Python
- Google Colab
- OpenCV
- PyTorch
- Diffusion models

### Project Structure

- `data/`: images and data
- `docs/`: documentation
- `notebooks/`: Google Colab notebooks
- `src/`: source code
- `outputs/`: generated results
- `experiments/`: tests and experiments

### Change of Project

I worked on this project for one period as part of my Undergraduate Research Project. After this period, **I changed projects**, moving to a new research project focused on the comparison between **RAG (Retrieval-Augmented Generation) and LLM Wiki**.

This repository contains the studies, experiments and materials developed during the period in which I worked with Artificial Intelligence for image editing.
